## Overview

Setting and clearing a family table can be unsanitary and repetitive. The Robotic Autonomous Table Swarm (RATS) uses swarm robotics strategies to automate this task: three autonomous robots coordinate to pick up plates and transport them to a target location.

<Figure src="tabletop-swarm/four-steps.jpg" caption="Using an overhead camera, the robots (1) start in any position, (2) navigate to equidistant points around the plate, (3) lift the plate, and (4) carry it to a target position" />

## My Contributions

### Multi-Agent Pathfinding

**My role:** sole contributor

Finding the fastest route from a starting position to an end position without colliding with other robots or plates. A control system then executes this path.

The A\* pathfinding algorithm treats other robots as dynamic obstacles, checking new potential routes against the other robots' paths in space and time. It also minimizes a cost function for each path, with different weights on translational and rotational motion.

### Control System and Higher-Level Robot Behavior

**My role:** wrote all of the low-level firmware, the control system, and 80% of the high-level routine

The goals were to:

1. Compute control signals to get the robots to a reference position and orientation
2. Send the control signals over Wi-Fi
3. Actuate the motors after receiving the reference signal
4. Combine 1, 2, and 3 to pick up and transport plates cooperatively

## System Design

An overhead camera detects the ArUco tags on the robots and plates. A laptop converts the image into a grid map, runs the multi-robot pathfinding algorithm, and converts each path into reference poses. A proportional controller computes motor commands, which are sent over Wi-Fi to an ESP32-C3 microcontroller on each robot.

**Live object avoidance:** pathfinding avoids obstacles in theory, but real-world dynamics can cause collisions with plates or other robots. Before each command is sent, the laptop runs a collision prediction model; if a risk is detected, evasive routines are sent to each robot.

## Robot Design

The biggest design challenge was fitting all three robots' ramps underneath the plate during lifting. To solve this, the design was compacted, minimizing the distance from the turntable to the ramp and lowering the overall robot height.

## Future Work

- Replace ArUco tag detection with machine vision, eliminating the tag mounts and plate tags
- Upgrade to an omni-wheel drivetrain with stronger motors, to move the plate more freely and lift heavier ceramic plates
- Move the software onto ROS 2 to make the system more robust
